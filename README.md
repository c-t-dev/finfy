# finfy

Projeto de finanças pessoais. Hoje o repositório guarda a documentação de referência do app **Minhas Economias**, levantada por engenharia reversa do portal web, para servir de base ao finfy.

## Onde está cada coisa

| Caminho | Conteúdo |
| --- | --- |
| [`wiki/`](wiki/README.md) | Documentação: funcionalidades, API, modelo de dados, problemas encontrados, testes e pendências |
| [`AGENTS.md`](AGENTS.md) | Instruções para agentes de IA (Claude Code, Codex, IA local) |
| [`CLAUDE.md`](CLAUDE.md) | Aponta o Claude Code para o `AGENTS.md` |

## Como trabalhar

Comece pelo [índice da wiki](wiki/README.md). Qualquer descoberta ou decisão vai para a wiki no mesmo commit, seguindo [`wiki/MANUTENCAO.md`](wiki/MANUTENCAO.md).
